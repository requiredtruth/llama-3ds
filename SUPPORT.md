## Directing a development request

A confirmed donor may open a **Funded direction** issue and include:

1. Asset sent.
2. Exact network.
3. Public transaction hash.
4. The specific feature, test, documentation area, or project direction they want expanded.

The first issue claiming an otherwise unclaimed **confirmed inbound transaction hash** receives operational request attribution for that transaction. This is not cryptographic proof of wallet ownership.

A donation can direct a request, but unsafe, illegal, private, proprietary, incompatible, or out-of-scope work can still be declined.

Never post a private key, seed phrase, wallet signature, exchange credential, or other secret in an issue.
